# Utkarsh Dwivedi — Portfolio

A responsive, single-page portfolio using Vidaloka + Space Mono, a shiny blue / purple / space-grey palette, liquid-glass panels, animated name typography, and subtle reveal animations.

## Files
- `index.html` — complete static website
- `vercel.json` — simple Vercel static deployment configuration

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are needed. Google Fonts load over the internet.

## Publish to your GitHub repository
1. Download and extract this ZIP.
2. Open your repository: https://github.com/utkarshdd122-design/WEB_DEVELOPMENT
3. Upload `index.html`, `vercel.json`, and this README (or replace the old portfolio files if appropriate).
4. Commit the changes to your chosen deployment branch.

If the repository already contains a project, review its files before replacing anything. Keep any unrelated files you need.

## Deploy on Vercel
1. Sign in at https://vercel.com/ and choose **Add New → Project**.
2. Import `utkarshdd122-design/WEB_DEVELOPMENT` from GitHub and authorize access if prompted.
3. For this plain HTML site, choose **Other** as the framework preset if Vercel asks; no build command is required and the output directory can be `.`.
4. Click **Deploy**. Vercel will provide a live URL.
5. Future pushes to the connected deployment branch can trigger redeployments.
